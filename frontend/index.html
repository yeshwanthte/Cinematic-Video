              Connecting the AI (free)
              
          
              The studio uses a free Hugging Face token kept on your server. It is never entered here, never stored in the browser, and never sent from your browser.
              
          
                
            
              1. Create a free account at huggingface.co, then Settings → Access Tokens → New token (type Read).
                2. 
            
              2. Vercel → your project → Settings → Environment Variables → add HF_TOKEN.
                3. 
            
              3. Recommended: add STUDIO_ACCESS_CODE and enter the same code above.
                4. 
            
              4. Redeploy, then press Save & test connection.
                5. 
            
              5. Optional, free monthly credits: deploy your own Wan 2.2 GPU server on Modal (US$30 compute/month) with the GitHub Action “Deploy video server to Modal”, then add MODAL_ENDPOINT_URL and MODAL_API_SECRET. Set Modal’s spend limit to $0.
                6. 
            
              6. Optional, paid: add RUNWAY_API_KEY to unlock Runway Gen-4.5 / Veo 3.1 in the model list.
                7. 
          
              
          
              Free accounts get 5 minutes of ZeroGPU time per day, PRO 40 minutes (Hugging Face docs, checked Oct 2026). It resets 24 h after first use. A 10 s Wan clip reserves about 1–1.5 min; an LTX clip 75 s.
              
          
              Prompt enhancement and photo analysis run in your browser for free. The optional hosted AI assistant (HF_ASSISTANT=on) uses Hugging Face Inference Provider credits — free accounts have none, so it is off unless you switch it on.
              
          
              Local development: copy .env.example to .env and run npm run dev.
              
        
              

        
              
          
              Audio
              
          
              AI audio: LTX-2.3 (free) generates sound together with the video. Wan 2.2 clips are silent. Runway Veo 3.1 (paid, optional) also has native audio.
              
          
              Your music: Film Studio mixes an uploaded track (volume, fade in/out) with any AI audio when you export. It is labelled as your track, never as AI.
              
          
              Not implemented: AI voiceover, AI sound effects or AI music generation.
