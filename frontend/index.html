      Final video
      Not available yet
      
        
      Combining scene clips into one video needs a backend render step (e.g. FFmpeg on a worker). That step is not implemented yet — /api/render returns 501. Download each scene clip and assemble them in your editor for now. Transitions you choose are saved with the project for when rendering ships.

      Connecting the AI (free)
      
          
      The studio uses a free Hugging Face token kept on your server. It is never entered here, never stored in the browser, and never sent from your browser.
      
          
        
            
      1. Create a free account at huggingface.co, then Settings → Access Tokens → New token (type Read).
        2. 
            
      2. Vercel → your project → Settings → Environment Variables → add HF_TOKEN.
        3. 
            
      3. Recommended: add STUDIO_ACCESS_CODE and enter the same code above.
        4. 
            
      4. Redeploy, then press Save & test connection.
        5. 
            
      5. Optional, paid: add RUNWAY_API_KEY to unlock Runway Gen-4.5 / Veo 3.1 in the model list.
        6. 
          
      
          
      Free accounts get ≈5 minutes of ZeroGPU time per day (≈5–10 short clips). It resets 24 h after first use.
      
          
      Local development: copy .env.example to .env and run npm run dev.
      
        
      

        
      
          
      Audio
      Roadmap
      
          
      The free Wan 2.2 models generate silent video. Native audio exists only on the paid Veo 3.1 models (via Runway). Music, ambient beds, AI sound effects, voiceover and uploaded audio are not implemented; the project data model reserves an audio track for them.
